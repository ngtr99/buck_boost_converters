In this project, a buck–boost converter system was designed and implemented using an ESP32 microcontroller to control the switching operation through PWM (Pulse Width Modulation). The buck converter was used to step down the input voltage, while the boost converter was used to step up the voltage, demonstrating both voltage reduction and amplification using switching techniques. The ESP32 generated a high-frequency PWM signal to drive the MOSFET, which acted as a fast electronic switch controlling energy transfer through the inductor. A diode provided a current path during the OFF state, and a capacitor was used to smooth the output voltage. Voltage measurement was performed using a resistor divider and the ESP32’s ADC, allowing real-time monitoring of Vout via Serial Plotter and OLED display. Experimental results showed that the output voltage depends on the PWM duty cycle, confirming the theoretical relationship between duty cycle and voltage conversion. Although some fluctuations were observed due to switching noise and component limitations, the system successfully demonstrated the operating principles of both buck and boost converters.
